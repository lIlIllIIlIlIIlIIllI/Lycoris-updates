# Lycoris 1.4.2-preview.3 · 모에니 콘텐츠 복구

Stage12.1 검토용 **Pre-release / versionCode54 / ARM64 Enhanced 통합 APK1개**입니다. 기존 정식1.4.1 및 Preview.1·Preview.2의 APK와 태그는 보존합니다.

## 수정 내용

- 사이트 선택값을 공개하기 전에 이전 목록 요청·상태를 초기화하여 새 모에니 요청이 취소되어 빈 화면으로 남는 경합 수정.
- 모에니 홈·전체 작품 목록·한국어 검색·작품 상세·찜 정보·월~일 편성표 연결 복구.
- 이전 사이트의 장르/형식/연도 필터를 모에니에 적용하지 않으며, 이전 분기 모드에서 옮겨도 모에니는 주간 편성을 표시.
- 강제 새로고침을 실제 API 요청에 전달하고, 정상 캐시는 네트워크/서버/응답 오류로 삭제하지 않음. 실패 이유·캐시/오프라인 표시·재시도 제공.
- 찜 원본 ID `moeni:<ID>`와 통합 보관함을 유지. 스냅샷이 없으면 이전/신규 캐시에서 복구하고, 보관함에서 공개 목록을 명시적으로 재조회하여 작품 정보를 복구 가능.
- 모에니 시청은 기존 외부 브라우저 방식 유지. 영상 재생 API를 추가한 버전이 아닙니다.

## 실제 확인

2026-11-13 **앱의 컴파일된 OkHttp 클라이언트와 파서로 실서비스**를 확인했습니다. 전체1,694개·홈12개·주간12개/7일·한국어 띄어쓰기 검색·실제 상세ID 일치. API는 현재200이며 목록/주간 스키마가 폐기된 상태가 아니었습니다. 포스터 endpoint도200 image/jpeg로 확인했습니다. 요일 분류를 실제 방송 날짜/시각으로 표시하지 않습니다.

## 자동 검증

- JVM **914개 성공**(기존885+신규29), 실패/오류/생략0. 기존 테스트 파일109개 유지.
- Debug/Enhanced 빌드 및 정확한 소스 커밋의 원격 CI 통과.
- Enhanced Lint 오류0, 경고254, Hint20(이전 프리뷰와 동일).
- 실제 Compose 정적 fixture8개 렌더·육안 검토. 초기 병행 렌더 경고2회 후 최종 독립 재렌더 경고0, 8개 이미지 생성. 실기기 캡처가 아닙니다.
- 기존 인증서·앱 ID 유지. ARM64 native19개 SHA256 모두 Preview.2와 동일. ZIP CRC·16KiB 정렬·서명 검사 통과.
- 기존 플레이어·AI·GGUF·LiteRT·자막·다운로드·기기 동기화·통합 인덱스 정책 유지. GGUF 기본/LiteRT 실험 opt-in 기본 OFF.

## 미검증 및 제한

**실제 Android 설치·기기 네트워크·터치·화면 회전·TalkBack·성능·PiP·영상/AI 동시 사용은 미검증**입니다. ADB 기기와 KVM 없이 Robolectric/호스트 HTTP/Layoutlib로 검증했습니다. 사용자 기기의 기존 오류 단일 원인을 logcat으로 확정한 것은 아니며, 확인된 앱 결함과 실제 API 상태를 구분하여 수정했습니다.

정상 캐시는 유지하지만 서비스가 향후 차단되거나 응답을 바꾸면 오류/캐시 안내가 나올 수 있습니다. 인증을 우회하지 않습니다. 통합 모드 찜 해제는 이전 Stage12와 같이 표시만 숨기고 원본 찜을 유지합니다. 복구 조회에도 없는 작품 ID를 삭제하거나 다른 작품으로 바꾸지 않습니다.

## 설치 / 기기 업데이트

기존 앱을 삭제하지 말고 **설정 → 앱 업데이트 → 업데이트 확인**에서 받거나 아래 APK를 기존 앱 위에 업데이트로 설치하세요. 같은 appId/인증서 및 code51/52/53→54 메타데이터 호환성을 검사했습니다. 실제 기기 설치 성공을 보장한 결과는 아니며 Android 최종 설치 확인/보안 검사는 유지합니다. 별도 시험판 채널이 없어 요청대로 기존 공개 update.json에 이 프리뷰를 연결합니다. 정식 Latest는v1.4.1로 유지합니다.

# Lycoris 1.4.2-preview.2 · 사이트 간 통합 보관함

**Stage12 검토용 Pre-release / ARM64 / versionCode53**. 기존 v1.4.1 정식 및 Preview.1 APK/태그는 보존합니다. code52는 이전 프리뷰에서 사용되어53을 사용했습니다.

## 변경 사항

- 사이트 전체 찜·시청 기록 통합 조회와 사이트 필터, 검증된 동일 작품의 중복 표시 방지.
- AniList/MAL와 시즌·형식·원제 등 보조 근거를 대조하는 보수적 매칭. 제목만 같으면 자동 통합하지 않습니다. 직접 연결·해제·조회 결과 캐시·차단/오류 구분.
- 사용자 요청으로 다른 사이트에서 실제 작품과 회차 후보를 확인하고 기존 상세/플레이어 경로로 이동.
- 통합 해제/숨김은 별도 상태입니다. **원본 찜·시청 기록·회차 키·다운로드·통계를 삭제하거나 다른 사이트 ID로 바꾸지 않습니다.**
- 소스 간 재생 위치를 복사하지 않습니다. 대상 사이트 자체의 기존 기록만 복원하며 없으면 처음부터 재생합니다. 4/4a·OVA·분할 회차는 자동 대응하지 않습니다.
- 설정 → 사이트 간 데이터 통합에서 각각 끄거나 연결/숨김을 관리합니다. 새 매핑/숨김/추가 기록 시각은 현재 기기에만 저장되며 기존 기기 동기화 프로토콜은 유지합니다.
- 모에니는 이전과 같은 웹 시청 소스로 유지합니다. 기존 Classic/Glass·mpv·AI·다운로드 기능을 보존합니다.

## 검증

- JVM **885개 통과**(기존788+신규97), 실패/오류/생략0. Debug/Enhanced 빌드 및 원격 CI 성공.
- Lint Error/Fatal0, Warning254, Hint20. 실제 Compose fixture8개 렌더링(실기기 캡처 아님).
- 기존 인증서·앱 ID 유지, ARM64 네이티브19개 이전 프리뷰와 SHA256 일치, ZIP CRC/16KiB 정렬/서명 검증 통과.
- **GGUF 기본**, LiteRT-LM 기존 실험 opt-in 기본 OFF. 새로운 모델/QNN 바이너리나 비밀정보를 포함하지 않습니다.

## 알려진 한계 / 미검증

- **Android 실기기 설치·앱 업데이트·사이트 간 실제 영상 재생·PiP·AI 동시 사용·성능은 미검증**입니다. ADB 장치 및 KVM이 없어 호스트 자동화/Robolectric/Layoutlib를 사용했습니다.
- 공식 AniList 실제 교차 참조는 개발 환경에서 Cloudflare403으로 차단되었습니다. 성공이나 모든 사이트 이용 가능을 주장하지 않습니다.
- Linkani/AnimeParadise의 포스터에서 추정된 AniList ID는 자동 근거로 사용하지 않습니다. 메타데이터가 부족하면 직접 확인이 필요합니다.
- 타 사이트 차단/인증/오프라인이면 원본 기록을 유지합니다. 조회는 사용자 요청 시에만, 동시2개/사이트당 상세최대3개로 제한합니다. 기존 blocking 공급자 호출은 자체 timeout까지 늦어질 수 있습니다.
- 과거 기록의 정확한 날짜는 만들지 않습니다. 작품 정보가 없으면 기록 보존 안내를 표시합니다.
- 신규 인덱스는 2,000개 작품 스냅샷·4MiB 한도이며 손상/쓰기 실패 시 원본 모드로 복귀합니다.

## 설치 및 앱 내 업데이트

앱을 삭제하지 말고 기존 Enhanced 위에 업데이트로 설치하세요. 동일 앱 ID/인증서와 상위 버전 메타데이터를 확인했으며 실제 기기 설치는 미검증입니다. 별도 시험판 채널이 없어 사용자 요청대로 기존 공개 update.json에 이 프리뷰를 연결합니다. **설정 → 앱 업데이트 → 업데이트 확인**으로 받을 수 있습니다. 자동 확인은 기존 주기를 유지합니다. Android의 최종 설치 확인/보안 검사는 유지합니다.

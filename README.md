# Lycoris Android 업데이트

Lycoris 통합 Enhanced ARM64 APK를 로그인 없이 내려받을 수 있는 공개 배포 저장소입니다. 앱 소스와 사용자 설정·키는 공개하지 않습니다.

- 정식 버전: [v1.4.1](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.1)
- 검토용 시험판: [1.4.2-preview.4](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.2-preview.4)
- 앱 내 업데이트: `main/update.json` — 검증된 Preview.4 / code55

온라인 자막 SubDL·SubSource 연결은 본인 API 키가 필요한 실험 기능입니다. 인증된 실서비스 검색·다운로드 및 실제 Android 기기 설치·재생은 미검증입니다. 기존 GGUF가 기본이며 LiteRT는 선택형으로 유지합니다. SubtitleCenter/AJATT 자동 검색은 API/이용 조건 확인 전 보류합니다.

기존 앱을 삭제하지 말고 업데이트로 설치하세요. Android의 설치 확인은 사용자가 처리합니다. 기존 Release·태그·APK를 보존합니다.

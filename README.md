# Lycoris — APK & Updates

Lycoris Android의 **공개 APK 배포 및 업데이트 정보 전용 저장소**입니다. 앱 소스, 사용자 데이터, API 키와 서명 키는 포함하지 않습니다.

## 현재 기기 업데이트 — 모에니 전체 콘텐츠 복구

**[1.4.2-preview.3 / code54](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.2-preview.3)**: 모에니 목록·검색·찜 정보·요일표와 소스 전환 경합을 수정합니다. 기존 통합 보관함·AI·다운로드·Classic/Glass는 유지합니다.

실제 공개 API를 앱의 OkHttp/파서로 조회해 전체1,694개·홈12개·월~일12개와 한국어 검색을 확인했습니다(2026-11-13 호스트 검사). 이전 필터를 모에니에 적용하지 않고, 분기 모드에서 모에니로 옮기면 주간 편성을 표시합니다. 정상 캐시를 유지하며 오류 원인/재시도·찜 정보 복구를 제공합니다.

모에니 영상 재생 기능을 추가한 버전이 아닙니다. 외부 브라우저 시청 경계와 기존 `moeni:<ID>`를 유지합니다. **실제 Android 설치·기기 네트워크·터치 조작·영상/AI/PiP 성능은 미검증**입니다. 기존 정식1.4.1 Latest 및 Preview.1·Preview.2의 APK/태그를 보존합니다. **설정 → 앱 업데이트 → 업데이트 확인**에서 받을 수 있습니다.

## 이전 프리뷰 — 사이트 간 통합 찜·시청 기록

**[1.4.2-preview.2 / code 53](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.2-preview.2)**: 통합 보관함·기록, 사이트별 필터, 작품 연결 관리, 사용자 확인 후 다른 사이트 회차 후보로 이동을 추가합니다.

원본 `saved_library`·`saved_watch_history`·사이트/회차 ID·다운로드·통계를 유지합니다. 통합 해제/숨김은 별도 상태이며 원본을 대량 삭제하지 않습니다. **소스 간 재생 위치를 복사하지 않고 대상 사이트 자체의 기존 기록만 복원**합니다. 메타데이터가 부족하거나 충돌하면 직접 확인하거나 연결을 보류합니다.

설정 → **사이트 간 데이터 통합**에서 각각 끄거나 숨김을 복원할 수 있습니다. 신규 연결/숨김은 이 기기 전용이며 기존 기기 동기화 프로토콜은 유지합니다. 모에니는 이전과 같은 웹 시청 소스입니다.

별도 시험판 채널이 없어 사용자 요청대로 기존 앱 업데이트 경로에 연결했던 버전이며 현재는 위의 Preview.3를 제공합니다. 기존 정식 **v1.4.1 Latest와 Preview.1 APK는 보존**합니다. 실제 Android 기기 설치·사이트 간 재생·PiP·성능은 미검증입니다. 공식 AniList 교차 참조는 현재 개발 환경에서 Cloudflare403으로 차단되어 실제 성공을 주장하지 않습니다.

## 이전 프리뷰 — 모에니 웹 시청 소스

**[1.4.2-preview.1 / code 52](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.2-preview.1)**: 설정 → 콘텐츠 / 영상 소스 → **모에니 · 웹 시청**을 선택할 수 있습니다. 목록·한국어 제목 검색·작품 정보·내 목록·월~일 요일표를 제공합니다.

모에니 시청은 **외부 브라우저의 원래 작품 페이지에서 회차를 선택하는 방식**입니다. 앱 내 mpv 재생·다운로드·AI 자막·브라우저 재생 위치 연동은 지원하지 않습니다. 외부 사이트 실제 영상 재생과 Android 실기기 동작은 미검증입니다. 다른 콘텐츠 소스의 기존 기능은 유지합니다.

모에니 프리뷰는 보존하며, 현재 기기 업데이트는 위의 Preview.3를 확인하세요. 아래 정식 1.4.1 및 과거 APK는 보존하며 Latest 정식 표시도 유지합니다. 새 버전을 설치한 뒤 낮은 versionCode APK로 되돌리는 것은 Android의 일반 업데이트 경로에서 지원하지 않습니다.

## 다운로드

**[APK 다운로드 · Releases](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases)** — GitHub 로그인 없이 사용할 수 있습니다. **최신 정식: [Lycoris 1.4.1 · 통합 Enhanced APK](https://github.com/lIlIllIIlIlIIlIIllI/Lycoris-updates/releases/tag/v1.4.1)**. 일반/AI 별도 APK 없이 하나만 배포합니다. 기존 GGUF 기본, LiteRT-LM 사용 허용은 기본 OFF입니다. Android 실기기 CPU/GPU·재생은 미검증이고 NPU는 비활성화입니다.

- ARM64 Android 8.0(API26) 이상. 기존 Lycoris Enhanced와 같은 앱 ID/서명을 사용합니다.
- 앱을 삭제하지 말고 APK를 기존 앱 위에 업데이트로 설치하세요.
- 처음 한 번 **1.4.1-preview.3(code43)** 이상을 설치하면 **설정 → 앱 업데이트**에서 새 버전을 확인·다운로드할 수 있습니다.
- 홈 진입 시 최대 6시간에 한 번 자동 확인합니다. 자동 확인은 설정에서 끌 수 있습니다.
- APK 다운로드는 사용자가 눌렀을 때 시작합니다. SHA256·파일 크기·패키지·기존 서명·상위 버전을 검사합니다.
- 설치 권한과 최종 설치 확인은 Android가 처리합니다. Play Protect 등 보안 검사는 변경하지 않습니다.
- 같은/구버전 APK는 앱 내부 설치 검사에서 거절됩니다. 이미 최신일 때 다시 다운로드할 필요가 없습니다.

## 공개 범위

이 저장소에는 APK, `update.json`, SHA256 체크섬, 사용 안내 및 배포 자동화 구성만 게시합니다. 공개된 APK는 누구나 받을 수 있습니다.

앱 코드 저장소와 기존 배포 이력은 별도로 유지합니다. 이 저장소의 소스 ZIP은 배포 구성일 뿐 Android 앱 소스가 아닙니다.

## 확인 범위

빌드·JVM 테스트·APK 서명 및 공개 다운로드를 확인합니다. 실기기 설치/재생·Play Protect 판정·배터리/성능은 별도 기기 검증이 필요합니다.

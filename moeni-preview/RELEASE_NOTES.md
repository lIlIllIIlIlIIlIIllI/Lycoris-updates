### 추가한 것

- 모에니의 공개 목록·갱신 작품·한국어 제목 검색·작품 상세·내 목록 연결

- 모에니 전용 작품 ID 및 주소 검사로 기존 소스의 추천·이어보기와 분리
- Classic/Glass 안내 화면, 오류 및 다시 시도, 외부 브라우저에서 작품 페이지 열기

### 지원 범위와 제한

**모에니의 시청은 외부 브라우저에서 회차를 선택하는 방식입니다. 앱 내 mpv 재생·다운로드·AI 자막·브라우저 재생 위치 연동은 지원하지 않습니다.** 공개 회차 수로 가짜 회차 ID나 시청 통계·신규 회차 알림을 생성하지 않습니다. 모에니의 분기 조회·장르/연도 메타데이터도 미지원입니다.

일반 브라우저 자동 검사에서 작품 페이지와 목록을 열었지만 실제 영상 재생 성공은 확인하지 못했습니다. 사이트의 자체 재생 응답을 복호화하거나 CAPTCHA·접근 제한을 우회하지 않았습니다. 제3자 API 재사용 약관과 영상 배포 권한은 미확인입니다. 공식 제휴 소스가 아닙니다. 사이트 상태와 운영 정책에 따라 접속·재생이 달라질 수 있습니다.

### 기존 기능 보존

기존 콘텐츠 소스, mpv, 자막·AI·Runtime, 다운로드, API 키·모델·기록·설정과 앱 ID·서명을 유지합니다. 기존 GGUF가 기본이며 LiteRT는 사용자가 허용해야 하는 실험 기능입니다. NPU 지원 성공을 주장하지 않습니다. **앱을 삭제하지 않고 기존 Enhanced 위에 업데이트 설치하세요.**
